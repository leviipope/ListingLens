# Listing Lens

Listing Lens is a web application designed to help users find products across multiple online marketplaces, track their prices, and receive notifications about new listings or price changes.

The goal is to make searching for second-hand products easier by bringing listings from different marketplaces into one place.

## Features

- **Marketplace Search** — Search and filter listings collected from multiple marketplaces.
- **Price Tracking** — Monitor listing prices and track changes over time.
- **Notifications** — Get notified when new listings match saved searches or when prices drop.
- **Listing History** — Track listing availability, including sold and archived items.

## Technologies

The project uses or plans to use the following technologies:

- **Python** — Backend development and data processing
- **Scrapy** — Web scraping and collecting marketplace listings
- **FastAPI** — Backend REST API
- **PostgreSQL** — Storing listings, price history, and user preferences
- **SQLAlchemy** — Database interaction
- **React** — Frontend user interface

## Project Status

Product Finder is currently in early development, with the initial focus on building the web scraping functionality and collecting marketplace data.
